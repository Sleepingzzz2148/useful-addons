# Tampermonkey Scripts

这是 Sleeping_zzz 自己编写和维护的油猴脚本仓库。

## 插件列表

| 名称 | 简介 | 作者 | 安装 | 文档 |
|---|---|---|---|---|
| Goj helper | 在 GOJ 页面左下角添加按钮，自动读取 vjudge.net 的 JSESSIONID 并绑定到 GOJ | Sleeping_zzz | [安装](https://github.com/Sleepingzzz2148/useful-addons/releases/latest/download/goj-helper.user.js) | [说明](./scripts/goj-helper/README.md) |
| GOJ AtCoder Rating | 在 GOJ 比赛榜单和用户页显示本地 AtCoder 风格 rating、performance、题目难度、rating 曲线、排行榜与 head-to-head 对比 | Sleeping_zzz2148 | [安装](https://github.com/Sleepingzzz2148/useful-addons/releases/latest/download/gojratings.user.js) | [说明](./scripts/goj-ratings/README.md) |
| GOJ Training Helper | 在 GOJ Hydro 训练页汇总各专题成绩，展示可动态屏蔽专题的训练总排名与平滑重排动画 | mine2307 | [安装](https://github.com/Sleepingzzz2148/useful-addons/releases/latest/download/goj-training-helper.user.js) | [说明](./scripts/goj-training-helper/README.md) |
| adofai in luogu | 在洛谷页面中添加 ADOFAI 风格的难度图标和 AC 动画 | Sleeping_zzz | [安装](https://github.com/Sleepingzzz2148/useful-addons/releases/latest/download/adofai-in-luogu.user.js) | [说明](./scripts/adofai-in-luogu/README.md) |

## 使用方法

1. 安装 Tampermonkey 或 Violentmonkey。
2. 点击对应脚本的安装链接。
3. 按提示安装脚本。
