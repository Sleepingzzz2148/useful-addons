# GOJ Training Helper

在 GOJ Hydro 训练页汇总各专题成绩，展示可动态屏蔽专题的训练总排名，并带有平滑重排动画。

> 脚本文件：[`test.user.js`](./test.user.js)
>
> 作者：mine2307

---

## 功能简介

本脚本用于在 GOJ Hydro 训练页快速查看整套训练的综合排名。

安装后，脚本会在训练页右上角添加：

```text
📊 总排名
```

点击后，脚本会：

1. 从当前训练页解析各章节 / 专题的 scoreboard 链接；
2. 逐个读取专题榜单 JSON 数据；
3. 汇总每位用户在所有专题中的 AC / 得分情况；
4. 生成训练总排名浮层；
5. 支持点击专题列头临时屏蔽该专题并动态重算排名；
6. 使用 FLIP 动画平滑展示排名变化。

所有统计均在当前浏览器页面内完成，不会上传到作者服务器。

## 使用方法

1. 登录并打开 [GOJ](https://www.goj.wiki/) 中的 Hydro 训练页面；
2. 点击页面右上角的：

   ```text
   📊 总排名
   ```

3. 等待脚本自动读取各专题 scoreboard；
4. 在弹出的「训练总排名」浮层中查看有效总分、原始总分和各专题成绩；
5. 点击专题列头可以屏蔽 / 取消屏蔽该专题；
6. 点击「↺ 全部重置」可以恢复全部专题参与计算；
7. 按 `Esc` 或点击「关闭」可以关闭浮层。

## 适用网站

脚本匹配以下网站：

```js
http://www.goj.wiki/d/*/training/*
https://www.goj.wiki/d/*/training/*
```

注意：

- 脚本不会在 `/scoreboard/` 页面展示入口按钮；
- 脚本依赖训练页中可解析到的 scoreboard 链接；
- 若当前训练没有章节 / 专题榜单，脚本会提示读取失败。

## 权限说明

本脚本不申请特殊油猴权限：

```js
// @grant        none
```

脚本会使用浏览器同源 `fetch` 读取当前 GOJ 训练下的专题 scoreboard JSON 数据。

本脚本不会读取跨站 Cookie，不会将训练成绩或用户数据上传到作者服务器。

## 常见问题

### 为什么按钮没有出现？

请检查当前页面是否符合训练页路径：

```text
/d/{domainId}/training/{trainingId}
```

如果页面路径包含 `/scoreboard/`，脚本会主动跳过，不显示入口按钮。

---

### 为什么提示未找到任何章节信息？

脚本会从训练页标题和 scoreboard 链接中解析章节 / 专题信息。

如果训练页结构发生变化，或页面中没有可访问的 scoreboard 链接，脚本可能无法生成总排名。

---

### 屏蔽专题会保存吗？

不会持久保存到浏览器存储中。

在同一次页面会话内，关闭并重新打开浮层时会保留当前屏蔽状态；刷新页面后会恢复默认状态。

---

### 这是 GOJ 官方排名吗？

不是。

这是脚本在浏览器本地根据训练页专题榜单即时汇总出的辅助排名，仅供训练统计和临时分析参考。
