# adofai in luogu

在洛谷页面中添加 ADOFAI 风格的难度图标和 AC 动画。

> 脚本文件：[`adofai-in-luogu.user.js`](./adofai-in-luogu.user.js)

---

## 功能简介

本脚本用于在洛谷页面中添加 ADOFAI 风格的难度图标和 AC 动画。

安装后，在洛谷页面中：

1. 题目列表和题目详情页的难度标签会被替换为 ADOFAI 风格的难度图标；
2. 题目详情页的满分分数会被替换为 ADOFAI 风格的 AC 动画；
3. 记录详情页的 Accepted 状态会被替换为 Pure Perfect 状态；
4. 用户主页会显示基于通过题目计算的 pp 值；
5. 关注/粉丝列表会显示用户的 pp 值。

---

## 安装

请先安装油猴脚本管理器：

- [Tampermonkey](https://www.tampermonkey.net/)
- 或 [Violentmonkey](https://violentmonkey.github.io/)

然后点击安装：

[安装 adofai-in-luogu.user.js](https://github.com/Sleepingzzz2148/useful-addons/releases/latest/download/adofai-in-luogu.user.js)
